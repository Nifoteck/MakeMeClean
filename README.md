# MakeMeClean

MakeMeClean is a branded cleaning service booking website for Wales, UK.

## Overview

MakeMeClean enables customers to book cleaning services online, manage recurring plans, and contact support. The platform features a multi-step booking wizard, customer dashboard, admin panel for managing bookings, staff, and applicants, as well as a staff dashboard for shift management. Recruitment and rescheduling flows are also supported.

## Tech Stack

- React + Vite + TypeScript
- Tailwind CSS
- Wouter (routing)
- Supabase (authentication, database, edge functions, storage)
- Brevo API (transactional email)
- pnpm

## Features

- Online booking and recurring plan management
- Admin dashboard for bookings, staff, and recruitment
- Staff dashboard for shift acceptance
- Secure authentication and role-based access
- Contact form and FAQ
- UK-compliant Terms & Conditions and Privacy Policy
